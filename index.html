¿Con qué tecnologías trabajas?

En frontend, React y TypeScript con Tailwind CSS. En backend, Node.js con Express o Java con Servlets/JSP. En datos, PostgreSQL (vía Supabase), MySQL y SQLite.

¿Haces solo frontend o también backend?

Ambos. Trabajo el ciclo completo: levantamiento del requerimiento, diseño de la base de datos, backend, interfaz, pruebas y despliegue.

¿Has trabajado con clientes reales?

Sí. La Casa de Mandi digitalizó los pedidos de una pastelería artesanal y Villas Doña Olga es el sitio de venta de un proyecto de lotes residenciales.

¿Dónde se despliegan tus proyectos?

Depende del proyecto: Netlify y GitHub Pages para sitios estáticos, Railway para aplicaciones con backend y base de datos, y servidores locales como Tomcat cuando el cliente lo requiere.
