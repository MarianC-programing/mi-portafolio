# Portafolio Web de Marian Barba

Sitio web personal de una sola página, construido solo con HTML, CSS y JavaScript, para mostrar mi perfil profesional, proyectos y formas de contacto. Está pensado para publicarse fácilmente en GitHub Pages sin necesidad de backend ni proceso de build.

## Descripción

Este proyecto presenta un portafolio responsive con una navegación simple, una sección principal de presentación, tecnologías, proyectos destacados y un formulario de contacto conectado a Formspree.

## Características

- Diseño responsive con navegación fija y menú móvil.
- Sección hero con presentación profesional y llamada a la acción.
- Bloque de habilidades y tecnologías usadas con chips e iconos.
- Galería de proyectos con estado, contexto, stack y enlaces a código o demo.
- Formulario de contacto funcional sin backend propio.
- Ajustes de accesibilidad como `focus-visible` y soporte para `prefers-reduced-motion`.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Formspree para el formulario de contacto
- GitHub Pages para despliegue
